# 快速开始

## 1. 构建开发环境
```bash
docker build -t edge-ai-dev:v1.0 -f Dockerfile.dev .
docker run -it --rm -v $(pwd):/workspace --network host edge-ai-dev:v1.0
```

## 2. 第一周目标
- [ ] Docker环境搭建，跑通地平线官方样例
- [ ] STM32 CAN回环测试
- [ ] STM32电机PID控制
- [ ] YOLOv8n导出ONNX，板端推理跑通

## 3. 常用命令
```bash
# 训练
cd 01_train && python3 train.py --data data.yaml

# 导出ONNX
python3 export_onnx.py --weights runs/train/car_yolov8n/weights/best.pt

# 模型转换
cd 02_convert && bash scripts/convert.sh int8

# 板端推理
cd 03_deploy/python && python3 inference.py --model yolov8n_car.bin --camera 0

# AEB主程序
python3 main.py --model yolov8n_car.bin --can can0

# HIL测试
cd 03_deploy/hil && python3 -m pytest test_aeb.py -v

# 日志回放
cd 05_system/logger && python3 replay.py --log aeb_log.bin
```
