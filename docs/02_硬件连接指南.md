# 硬件连接指南

## 系统接线图
```
地平线AI板                    STM32F407                底盘
┌──────────┐                ┌──────────┐           ┌──────────┐
│ USB摄像头 │→USB           │ CAN1_RX  │←CAN_H/L→ │ 电机驱动  │→电机
│          │                │ CAN1_TX  │           │          │
│ USB-CAN  │←CAN_H/L→      │ TIM2_CH1 │→PWM      │ 舵机      │→转向
│          │                │ TIM2_CH2 │→PWM      │          │
│ 5V输出   │→5V            │ TIM3     │←编码器   │ 编码器    │
└──────────┘                └──────────┘           └──────────┘
```

## CAN总线连接
- AI板USB-CAN适配器的 CAN_H → STM32 CAN收发器的 CAN_H
- AI板USB-CAN适配器的 CAN_L → STM32 CAN收发器的 CAN_L
- 两端共地（GND连在一起）
- CAN_H和CAN_L之间接120Ω终端电阻（如果总线两端都有设备，各接一个）

## STM32引脚
| 功能 | 引脚 | 说明 |
|------|------|------|
| CAN1_TX | PA12 | 接CAN收发器TXD |
| CAN1_RX | PA11 | 接CAN收发器RXD |
| 电机PWM | PA0 | TIM2_CH1, 20kHz |
| 舵机PWM | PA1 | TIM2_CH2, 50Hz |
| 电机方向 | PB0 | 高=反转, 低=正转 |
| 编码器A | PA6 | TIM3_CH1 |
| 编码器B | PA7 | TIM3_CH2 |

## 供电
- 地平线板: 5V/3A (USB-C或DC)
- STM32: 5V (从地平线板取电或独立供电)
- 电机: 12V锂电池 (经电机驱动板)
- 舵机: 5V/2A (独立稳压，不要和逻辑共电)
